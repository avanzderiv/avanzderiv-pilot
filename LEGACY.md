# Avanzderiv Pilot 2.0 Legacy Status

Avanzderiv Pilot Edition 2.0 is closed for public self-service deployment.

This repository remains visible only for historical reference, release traceability, repository continuity, and public record of the Pilot 2.0 phase.

Pilot 2.0 is no longer available as a public self-service deployable edition.

Public deployment artifacts previously associated with Pilot 2.0 are no longer available for public use, including setup scripts, setup templates, deployment bundles, public install commands, public run commands, and public container pull instructions.

Pilot 2.0 software artifacts, where retained, are retained under controlled access and are not advertised for public deployment.

The current product direction is Avanzderiv 3.0 Enterprise, available through demo, assisted deployment, integration support, and enterprise onboarding.

Avanzderiv 3.0 Enterprise is not distributed as a public self-service download.
