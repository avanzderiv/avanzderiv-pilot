# Avanzderiv Pilot Edition 2.0 — Legacy Reference

Public self-service deployment of Avanzderiv Pilot Edition 2.0 is now closed.

This repository remains visible only for historical reference, release traceability, repository continuity, and public record of the Pilot 2.0 phase.

Pilot Edition 2.0 is no longer available as a public self-service deployable edition.

## Deployment Artifact Status

Public deployment artifacts previously associated with Pilot Edition 2.0 are no longer available for public use.

This includes:

- setup scripts
- setup templates
- deployment bundles
- public install commands
- public run commands
- public container pull instructions

Any previous Pilot 2.0 setup, install, pull, download, or execution commands are deprecated and should no longer be used.

## Software Artifact Status

Pilot 2.0 software artifacts are no longer part of a public self-service distribution channel.

Container images or package artifacts, where retained, are retained under controlled access and are not advertised for public deployment.

## Current Product Direction

The current product direction is **Avanzderiv 3.0 Enterprise**.

Avanzderiv 3.0 Enterprise is available through demo, assisted deployment, integration support, and enterprise onboarding.

Avanzderiv 3.0 Enterprise is not distributed as a public self-service download.

## Repository Status

This repository is intentionally kept public as a historical reference.

It is not an active public deployment or distribution channel.
